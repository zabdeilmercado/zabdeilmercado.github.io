01
Current capstone / Health data interoperability

IDG4H

An offline-first health data gateway designed for clinics working with unreliable connectivity. It synchronizes records from a local SQLite edge node to a FHIR-aligned PostgreSQL registry through durable, retryable operations.

  • TypeScript
  • Node.js
  • SQLite
  • PostgreSQL
  • HL7 FHIR
A closer look +

Inside the project

The npm workspaces monorepo separates the edge node, central server, shared schemas, and a synchronization experiment. Current work covers audited CSV and Excel imports, idempotent synchronization, retry recovery, optimistic conflict handling, and automated tests.

IDG4H is an active capstone prototype. Source-specific adapters and several field workflows are still in progress.

02
Web application / Personal finance

Fin-Track

A finance application with views for transactions, categories, and a dashboard. Built with Vue, with shared state for accounts, income, expenses, and financial summaries.

  • Vue 3
  • Pinia
  • Vuetify
  • Chart.js
A closer look +

Inside the project

Accounts, transactions, and categories feed computed summaries, including total balance and savings rate. Separate views organize the dashboard, transactions, and settings.

The finance store currently initializes data in memory. This repository is a development project, with room to extend persistence and account workflows.
